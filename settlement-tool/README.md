# 하이포스 업체 정산 도구

하이포스(HiPOS)에서 뽑은 "수수료매출내역(거래처별)" 전산원본 엑셀로
출하업체 월 정산 자료를 자동 생성하는 도구 모음입니다.

**기본은 `skill/`(Claude Code 스킬)을 쓰세요.** `.xlsx`/`.zip`을 확인창 한
번으로 통째로 받을 수 있고, OCR 인식률도 더 높습니다. `index.html`(웹 링크)은
클로드 계정이 없는 사람에게 링크만 공유하고 싶을 때 쓰는 대안입니다 —
자세한 이유는 아래 "왜 두 가지 버전이 있나" 참고.

- **결과물1** — 정산 총액 증빙 요약표 (기존 11개 컬럼 양식 그대로).
  과세공급가액/부가세는 과세지급액(총액)을 기준으로 역산해서, 하이포스
  원본의 반올림 오차(1원 단위)가 재현되지 않도록 처리합니다.
- **결과물3** — 업체별 세금계산서 발행 요청 표. 작성일자·직매장
  대표자명을 입력하면 모든 업체 블록의 안내문구에 자동 반영됩니다.
  하이포스가 붙이는 합계행(사업자번호가 비어있는 행)은 자동 제외됩니다.
  상단에 결과물3 소계 합계와 결과물1 총계가 맞는지 수식으로 바로 보여주는
  검산 섹션이 있습니다 (일치/불일치를 초록/빨강으로 표시).
- **JPEG 파일명 매칭** — 출하내역서를 스캔한 JPEG를 zip으로 올리면,
  전산원본과 대조해서 어느 스캔이 어느 업체 것인지 자동으로 찾아 파일명을
  바꿔줍니다. 이름 OCR 하나만 보지 않고, 면세지급액·과세공급가액·부가세
  ·과세지급액·총지급예정액계·순매출금액·매출수수료 중 **3개 이상이 한
  업체와만 동시에 일치**할 때만 "확정"으로 표시하고, 애매한 건 "확인
  필요"로 남겨서 잘못된 업체에 파일이 매칭되는 사고를 방지합니다.

## 구성

- `skill/` — Claude Code용 스킬 패키지 원본 (권장). `scripts/package_skill.py`로
  `.skill` 파일로 묶어서 배포할 수 있습니다. 채팅에 전산원본(+출하내역서
  스캔 zip)을 올리면 진짜 `.xlsx`/`.zip`을 바로 만들어줍니다.
- `scripts/` — `skill/scripts/`와 동일한 파이썬 스크립트 (`generate_report1.py`,
  `generate_report3.py`, `rename_jpegs.py`). 스킬 없이 직접 돌려볼 때 씁니다.
- `index.html` — 브라우저에서 바로 쓰는 웹 도구(아티팩트). 파일 업로드부터
  결과 확인·다운로드까지 전부 브라우저 안에서 처리되며 서버로 데이터를
  전송하지 않습니다 (SheetJS, Tesseract.js OCR 엔진, JSZip 전부 내장, 완전
  오프라인 동작).

## 왜 두 가지 버전이 있나

클로드 아티팩트(웹 도구)의 파일 저장 기능은 `.xlsx`/`.zip` 확장자를
지원하지 않습니다. 그래서 `index.html`은:
- 결과물1을 CSV로, 결과물3을 HTML로 내보냅니다 (엑셀에서 열리긴 하지만
  진짜 `.xlsx`는 아닙니다).
- JPEG 매칭 결과는 zip으로 한 번에 못 받고, 확정된 파일을 한 장씩 저장
  확인창을 눌러가며 받아야 합니다.
- OCR도 브라우저에 내장 가능한 경량 한글 언어팩(fast 모델)을 써서, 데스크톱
  tesseract보다 인식률이 낮습니다 (같은 60장 기준 확정 50장 vs 58장).

반면 Claude Code 채팅(스킬)에서는 이런 제약이 없어서, `SendUserFile`로
진짜 `.xlsx`와 진짜 `.zip`을 확인창 한 번으로 통째로 전달할 수 있고,
데스크톱 tesseract를 그대로 써서 인식률도 더 높습니다.
