# 하이포스 업체 정산 도구

하이포스(HiPOS)에서 뽑은 "수수료매출내역(거래처별)" 전산원본 엑셀로
출하업체 월 정산 자료를 자동 생성하는 도구 모음입니다.

- **결과물1** — 정산 총액 증빙 요약표 (기존 11개 컬럼 양식 그대로).
  과세공급가액/부가세는 과세지급액(총액)을 기준으로 역산해서, 하이포스
  원본의 반올림 오차(1원 단위)가 재현되지 않도록 처리합니다.
- **결과물3** — 업체별 세금계산서 발행 요청 표. 작성일자·직매장
  대표자명을 입력하면 모든 업체 블록의 안내문구에 자동 반영됩니다.
  하이포스가 붙이는 합계행(사업자번호가 비어있는 행)은 자동 제외됩니다.

## 구성

- `index.html` — 브라우저에서 바로 쓰는 웹 도구. 파일 업로드부터 결과
  확인·다운로드까지 전부 브라우저 안에서 처리되며 서버로 데이터를
  전송하지 않습니다. (SheetJS 라이브러리 내장, 별도 설치 불필요)
- `scripts/` — 같은 로직의 파이썬 버전 (`generate_report1.py`,
  `generate_report3.py`). 실제 서식이 살아있는 `.xlsx` 결과물이
  필요할 때 사용합니다.
- `skill/` — Claude Code용 스킬 패키지 원본. `scripts/package_skill.py`로
  `.skill` 파일로 묶어서 배포할 수 있습니다.

## 로컬에서 웹 도구 열어보기

`index.html`을 브라우저로 직접 열면 됩니다 (별도 서버 불필요).
